# Data sources and attribution

## UCI Bike Sharing

This project uses the hourly data from the Bike Sharing dataset in the UCI
Machine Learning Repository.

- Dataset page: https://archive.ics.uci.edu/dataset/275/bike%2Bsharing%2Bdataset
- DOI: https://doi.org/10.24432/C5W894
- Citation: Fanaee-T, H. (2013). Bike Sharing [Dataset]. UCI Machine Learning
  Repository.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).

The raw archive is excluded from Git. Dataset terms require attribution when
redistributing or adapting the data. This project is independent and is not
endorsed by UCI.
